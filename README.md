## Publishing and review

`britecity.md` is generated from BRITECITY's private content systems and published only after review. The public export should:

1. Include only approved public facts and guidance.
2. Link back to the relevant canonical BRITECITY.com pages.
3. Exclude secrets, credentials, private URLs, customer-specific information, internal prompts, and operational procedures.
4. Preserve real update dates rather than manufacturing freshness.
5. Record material changes in the repository history.

See [PUBLICATION_POLICY.md](PUBLICATION_POLICY.md) for the public-export standard.
